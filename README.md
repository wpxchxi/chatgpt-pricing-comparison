## Pro 500 多出来的钱买的是什么

Pro 500 比老 Pro 200 贵 300 美元，用量从 20 倍涨到 25 倍，但这不是重点。真正的差异是两项独家功能：

**Ultrafast**。GPT-6 Astra 的高速模式，Codex 里 token 生成速度最高提升 8 倍，大约每秒 300 token。Sam Altman 发布当天的原话是：“Ultrafast 快到我再也不想回去。”账要这么算：Ultrafast 消耗套餐内含额度的速度是标准模式的 8 倍。Pro 500 的 25 倍额度如果全程跑 Ultrafast，实际只相当于约 3 倍 Plus 的标准速度 Astra 工作量，比 Pro 100 按标准速度跑还少；用购买的 credits 跑则按 6 倍费率扣。中间还有一档 Fast 速度，额度消耗 2.5 倍、credits 消耗 2 倍，适合折中。

所以合理的用法是：默认标准速度，只有当你盯着 agent 写代码、等待时间真的值钱时才切 Ultrafast。任务都是晚上挂机跑、早上看结果的话，这个功能基本用不上。

**Agents API 计算机使用**。在 Codex 和 ChatGPT Work 里让 agent 直接操作电脑，Pro 500 是唯一支持的个人套餐（Enterprise 也有）。

顺带一提，OpenAI 本周取消了 GPT-6.1 Astra，所以 Ultrafast 目前加速的仍是 GPT-6 Astra，GPT-6.1 Sol Ultrafast 官方只说“即将推出”，没有给日期。另外 Pro 500 目前只能在 ChatGPT 网页端订阅，App Store 渠道买不了。

## 常见问题

**ChatGPT Pro 有官方优惠码吗？**

没有。官方不发优惠码，实质优惠以 credits 形式出现：学生的 100 美元 credits、Pro 200 老用户的 62,500 credits 补偿。立减码目前来自第三方办理平台，比如本文提到的 ACCPAY。

**Pro 200 退订后重新订阅，能恢复 20 倍额度吗？**

不能。不符合保留条件的订阅一律按新额度（10 倍）执行。想保住老额度，保持订阅持续有效是唯一办法。

**在 Pro 200 上买 credits 能解锁 Ultrafast 吗？**

不能。Ultrafast 只在 Pro 500 提供个人版本（符合条件的 Enterprise 和 Edu 工作区也可用），买多少 credits 都不解锁。

**credits 怎么折算成钱？**

1 credit 约合 4 美分。GPT-6 Astra 标准速度每百万输出 token 扣 1,250 credits，GPT-6.1 Sol 每百万 250 credits。购买的 credits 有效期 12 个月。

**Pro 可以年付吗？**

不可以。官方明确 Pro 只按月计费，也不支持一次预付多个月。Pro 500 跑满一年是 6,000 美元。

**客服能帮我重置用量额度吗？**

不能。官方明确客服无权重置限额，只能核查用量是否被错误计算、或重置后额度是否正常恢复。
